# 网页房间功能说明

网页房间是 `apps/web-room/` 下的独立静态客户端。它复用 syncRoom 的房间协议和服务端能力，但提供浏览器扩展之外的完整房间工作台：公告、播放器、聊天室、房间信息、成员列表、授权管理和点播解析。

## 适用场景

- 用户不想安装扩展，只需要打开网页加入房间。
- 房主可通过临时平台授权解析需要登录态的播放源。
- 房间内需要文本聊天、系统消息、私有弹幕和可选语音。
- 运维希望把网页入口和 WebSocket/API 服务分开托管。

网页房间不替代浏览器扩展。扩展仍然适合“从当前网页直接同步当前视频”的使用方式；网页房间更适合“进入一个房间工作台后集中观影和聊天”的方式。

## 房间与邀请

房间创建后会生成 `roomCode:joinToken` 格式的邀请字符串。其他用户在入口页的“房间邀请”输入框中粘贴这一整串内容即可加入房间。

网页用户的默认昵称为 `网页用户` 加两位随机大写字母，并保存在当前浏览器本地存储中。同一浏览器再次进入网页房间时会复用该昵称。

## 播放器

网页房间在 Media Chrome 控件之上做了一层轻量播放引擎分发。DASH/MPD 与 HLS/m3u8 由 Shaka Player 播放，MP4 等普通直链由原生 `<video>` 播放，FLV/TS 直播源由 mpegts.js 播放。没有选择视频时也会显示播放器控件，但进度条不会允许拖动。

当前播放源选择策略：

- DASH/HLS 使用 Shaka Player。
- MP4 等普通直链使用原生 `<video>`。
- FLV/TS 直播源使用 mpegts.js。
- 候选清晰度会优先选择浏览器兼容性更好的 AVC/H.264，而不是 HEVC。

视频标题显示在播放器控件内部，避免占用公告栏和播放器上方空间。

## Bilibili 授权与点播解析

授权入口收纳在“授权管理”弹窗中，当前 Bilibili、爱奇艺和虎牙提供 QR 二维码授权。虎牙公开直播间仍可在不登录时解析；需要登录态的虎牙内容可使用房主临时授权。

授权只允许房主操作：

- 房主可以启动 QR 授权、查看安全的授权状态、退出授权和发起点播解析。
- 成员只能看到成员安全状态，不能操作房主授权。
- Cookie、CSRF、SESSDATA、Authorization header 等真实凭据只保存在服务端临时授权状态中，不下发给成员浏览器。

点播解析会把已支持平台的页面链接解析为可播放候选项。房主可以在开始播放前选择清晰度，并选择 `proxy` / `shared` 策略。

## proxy 与 shared

`proxy` 和 `shared` 是两个独立策略：

| 策略           | 含义                                                                                           |
| -------------- | ---------------------------------------------------------------------------------------------- |
| `proxy=true`   | 服务端用房主临时授权解析并代理媒体 manifest/segment，成员浏览器只访问 syncRoom `/proxy/*` 地址 |
| `proxy=false`  | 成员浏览器直接加载 provider 直链，可能受 CORS、Referer、IP 绑定或过期影响                      |
| `shared=true`  | 解析时允许使用房主授权能力，适合会员或需要登录态的内容                                         |
| `shared=false` | 解析时按匿名或无 cookie 能力处理，会员内容可能降级或失败                                       |

首发推荐路径是 `proxy=true + shared=true`。当直链播放失败时，网页房间会把错误提示放在房间设置区域，不破坏播放器布局，并允许房主切回 proxy 播放。

## 聊天、系统消息与弹幕

网页房间包含三类实时消息：

- 文本聊天：展示为群聊气泡，带发送者和时间。
- 系统消息：用户加入、离开、开麦、闭麦时按时间顺序居中显示。
- 房间私有弹幕：通过播放器控制栏输入，只在当前房间内实时飘过一次。

聊天和弹幕都不写入持久化存储。刷新页面、重启服务或重新加入房间后，不期望恢复历史消息。

弹幕会跟随播放器暂停和恢复：暂停时弹幕停止移动，已飘过的弹幕不会因为暂停或恢复而重新出现。

## 语音

网页房间复用 syncRoom 的 LiveKit 语音能力。语音入口位于聊天室发送按钮旁边，以麦克风图标呈现。

- 成员默认未开麦。
- 点击麦克风后请求服务端 `voice:access`，再连接 LiveKit。
- 开麦和闭麦会产生系统聊天消息。
- 语音服务不可用时，错误提示显示 3 秒后自动消失。

LiveKit 只承载语音，不承载主视频流。主视频由网页房间播放引擎加载 URL 播放。

## 状态与持久化边界

- 房间聊天和弹幕：会话级，不持久化。
- 平台授权：服务端临时状态，不写入 durable room store。
- 网页房间重连状态：只保存安全的 room code、member token、server URL 等必要信息。
- 房主授权在房主离开、房间销毁、服务重启或房主离线超过服务端 TTL 后清理。
