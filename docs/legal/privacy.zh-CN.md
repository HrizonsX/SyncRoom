# syncRoom 隐私权政策

生效日期：2026-06-07

本隐私权政策适用于浏览器扩展 syncRoom 以及同一项目中的网页房间客户端（以下简称“本项目客户端”）。本政策说明本项目客户端在提供多人同步播放、网页房间、可选房间语音、视频站点临时授权和连接诊断功能时会处理哪些信息、如何使用这些信息，以及用户可如何控制相关数据。

## 1. 处理的信息类型

本扩展仅处理实现核心功能所必需的信息，主要包括以下几类：

### 1.1 个人身份信息

本扩展可能会读取您在哔哩哔哩页面中可见的显示名称或用户名，并将其用作同步房间中的成员显示名称，用于标识是谁发起了播放、暂停、切换视频或倍速调整等操作。对于通用 HTML5 视频页面，本扩展不会为了同步功能额外读取该网站的账号资料。

本扩展不会主动收集真实姓名、身份证号、电子邮件地址、电话号码或邮寄地址。

### 1.2 网络记录

本扩展会读取当前受支持视频页面的网址，用于：

- 判断当前页面是否为支持同步的 B 站页面或通用 HTML5 `<video>` 页面
- 识别当前共享的视频
- 在房间成员之间同步当前共享视频

### 1.3 用户活动

本扩展会处理与同步播放直接相关的播放器状态和用户操作，包括：

- 播放或暂停状态
- 当前播放进度
- 播放速度
- 与同步控制相关的页面交互结果

这些信息仅用于实现同步播放功能，不用于广告、推荐画像或跨网站跟踪。

### 1.4 网站内容

本扩展可能会读取当前视频页面中的有限内容，例如：

- 视频标题
- 视频来源和页面标题
- 视频标识信息（如 B 站页面中的 `bvid`、`cid` 等）
- 当前页面对应的视频信息

这些内容仅用于识别和同步当前视频。

### 1.5 语音数据

当服务端启用 LiveKit 语音功能时，房间成员可以连接到房间语音。麦克风默认关闭；只有在用户主动点击开麦并授权浏览器麦克风权限后，本扩展才会采集麦克风音频并通过配置的 LiveKit 服务传输给同一语音房间中的成员。本扩展不会为了语音功能在浏览器本地长期保存麦克风音频。

LiveKit 仅用于房间语音，不用于分发共享观影的主视频流。网页房间中的 Bilibili 视频通过 URL 播放器和 SyncRoom proxy 播放，不会作为 LiveKit 视频 track 发布。

### 1.6 临时视频站点授权

当网页房间房主主动使用平台二维码授权时，服务端可能会临时保存完成 provider 请求所需的授权凭据，例如 Cookie、CSRF 或等效令牌。这些凭据仅保存在服务端临时授权状态中，用于房主所在房间的 provider 解析和 proxy 播放。

临时授权凭据不会写入持久化 room store、Admin 页面、审计日志、错误响应或成员可见 payload。成员不会收到房主的视频站点凭据。

### 1.7 网页房间文字聊天

网页房间支持房间内文字聊天。聊天消息会通过同步服务器实时广播给同一房间的成员；服务端不把聊天记录写入数据库或持久化房间存储，网页客户端也只在当前页面生命周期内保留消息。刷新页面或重启服务端后，既有聊天记录不要求恢复。

## 2. 信息的使用方式

本扩展仅将上述信息用于以下目的：

- 识别当前受支持视频页面及其视频内容
- 创建、加入和维持同步播放房间
- 在房间成员之间同步播放、暂停、进度和倍速
- 在用户主动开麦时传输房间语音
- 在网页房间内实时广播文字聊天消息
- 在房主授权后解析 provider 视频、剧集或直播源
- 在扩展界面中展示房间状态、共享视频信息和成员显示名称
- 维持连接状态、诊断连接问题和改进功能稳定性

本扩展不会将这些信息用于：

- 广告投放
- 向第三方出售数据
- 与核心功能无关的用户画像
- 跨网站跟踪用户行为

## 3. 远程通信

为实现扩展功能，本扩展可能会与以下远程端点通信：

### 3.1 视频站点接口

本扩展可能访问哔哩哔哩相关接口，以读取当前登录状态下可用的显示名称等必要信息。对于通用 HTML5 视频页面，本扩展主要读取页面中已有的标准视频元素、页面 URL 和标题信息。

### 3.2 同步服务器

本项目客户端会连接用户配置或使用的同步服务器，以在房间成员之间传递同步播放所需的数据，例如：

- 房间状态
- 当前共享的视频信息
- 当前播放状态
- 房间文字聊天消息
- 视频站点授权状态、解析结果和 provider 播放描述符

如果您自行配置第三方同步服务器，则相关数据会发送到该服务器，数据的保存方式和访问控制也将受到该服务器部署方式的影响。

当房主选择 `proxy=true` 播放 provider 内容时，媒体 manifest 或分片可能会经由同步服务器代理。此时同步服务器会处理对应的媒体请求、Range 请求和流量统计。代理不会把房主 Cookie 或授权 header 下发给成员，但运营者可以从服务器侧看到聚合后的 proxy 请求量和字节数。

### 3.3 LiveKit 语音服务

如果同步服务器启用了 LiveKit 语音功能，本扩展会使用服务端签发的短期语音令牌连接对应 LiveKit 服务。用户开麦后，麦克风音频会通过该 LiveKit 服务传输；用户静音时不会发布麦克风音频。

## 4. 本地存储

为了提供连续的使用体验，本扩展可能会在浏览器本地存储以下信息：

- 房间代码
- 加入房间所需的令牌或会话标识
- 成员标识
- 显示名称
- 最近一次房间状态
- 服务器地址配置

这些信息主要保存在浏览器扩展存储空间或网页房间的浏览器本地存储中，用于维持会话和恢复客户端状态。网页房间不会把视频站点临时授权凭据保存在浏览器本地存储中。

## 5. 数据共享与披露

本扩展不会出售您的个人数据。

本扩展仅会在实现同步播放功能所必需的范围内，将相关信息发送给：

- 您所连接的同步服务器
- 同一同步房间中的参与方

共享的信息可能包括：

- 显示名称
- 当前共享的视频信息
- 当前播放状态（如播放、暂停、进度、倍速）
- 房间文字聊天消息
- 用户主动开麦时的房间语音音频

除非法律法规要求，否则本扩展不会主动向无关第三方披露这些信息。

## 6. 远程代码说明

本扩展不会下载、注入或执行远程代码。

扩展所执行的脚本均随扩展安装包一同分发，并在本地运行。与远程服务器的通信仅用于数据传输和同步功能，不用于动态加载可执行代码。

## 7. 数据安全

本扩展会尽合理努力保护所处理信息的安全，减少未经授权的访问、使用或披露风险。但任何网络传输或电子存储方式都无法保证绝对安全。

如果您自行配置第三方同步服务器，相关数据安全还取决于该服务器本身的配置和运维情况。

## 8. 用户控制

您可以通过以下方式控制相关数据：

- 停止使用或卸载本扩展
- 退出同步房间
- 清除浏览器中该扩展保存的本地数据
- 修改或移除同步服务器地址配置

## 9. 儿童隐私

本扩展并非专门面向儿童设计，也不会故意收集儿童的敏感个人信息。
